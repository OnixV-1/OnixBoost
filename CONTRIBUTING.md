# Contributing

OnixBoost — **source-available** проект с проприетарной лицензией ([LICENSE](LICENSE)).

Публичный код можно **изучать** и собирать локально для себя.  
Внешние Pull Request по умолчанию **не принимаются**.

## Как помочь

- Баги и предложения — [Issues](https://github.com/OnixV-1/OnixBoost/issues)
- Уязвимости — только через [SECURITY.md](SECURITY.md)
- Прочие вопросы — [Telegram OnixV](https://t.me/Onix_Vbot)

Если автор отдельно попросит патч или согласует вклад — условия передачи прав будут оговорены заранее.
