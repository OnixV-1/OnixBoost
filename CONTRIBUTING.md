# Contributing

Спасибо за интерес к OnixBoost.

## Что открыто

- Клиент и UI (`OnixBoost/`)
- Установщик (`OnixBoost.Setup/`)
- Публичная документация (`README.md`, `SECURITY.md`, и т.д.)

## Что закрыто

- Серверные endpoint’ы, ключи и приватные runtime-конфигурации  
- Перепубликация изменённых или неполных сборок (см. [LICENSE](LICENSE))

## Сборка клиента

Требования: Windows, .NET 8 SDK.

```bash
dotnet publish OnixBoost/OnixBoost.csproj -c Release -r win-x64 --self-contained true
```

Запуск скомпилированного клиента для отладки — на вашей ответственности; для обычного использования берите официальный Setup из Releases.

## Какие PR принимаются

Желательны небольшие, проверяемые изменения:

- исправления UI / локализации / документации  
- воспроизводимые багфиксы в открытом клиентском коде  
- улучшения сборки и CI без раскрытия закрытой инфраструктуры  

Не принимаются PR, которые:

- добавляют сторонние «обходные» инструкции или вредоносные payload’ы  
- публикуют секреты, endpoint’ы или приватные конфиги  
- предлагают перелицензировать проект без согласования  

## Баги и идеи

Откройте [Issue](https://github.com/OnixV-1/OnixBoost/issues).  
Уязвимости — только через [SECURITY.md](SECURITY.md), не в публичных Issue.
