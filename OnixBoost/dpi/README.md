# Runtime extras (not included)

Готовые списки хостов, стратегии, бинарники и **серверные** `client*.json` **не входят** в публичный исходник.

Положи свои файлы локально:

- `core/client*.json` — по образцу `*.example.json`
- `args/`, `lists/`, `bin/` — свои runtime-файлы

Сборка UI возможна без них; полный функционал — только с собственным runtime.
