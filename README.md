## Что это

**OnixBoost Soft** — Windows-приложение от [OnixV](https://t.me/Onix_Vbot) для управления сетевыми маршрутами выбранных приложений.

Это не системный VPN: включается только трафик сервисов, которые вы выбрали карточками.  
Остальной трафик ПК (в том числе игры вроде Steam / CS2) продолжает использовать обычное подключение.

---

## Как это работает

OnixBoost создаёт независимые правила маршрутизации для выбранных приложений.  
Включение карточки влияет только на трафик соответствующего сервиса; системный маршрут по умолчанию и трафик других программ не изменяются.

| Карточка | Технически |
|----------|------------|
| **Discord** | DPI-профиль на базе winws + [WinDivert](https://reqrypt.org/windivert.html): перехват и обработка пакетов по hostlist Discord (чаты, голос, демонстрация экрана в обычном клиенте) |
| **YouTube / Twitch** | Локальный mixed-прокси и системный PAC: в браузере (Chrome / Edge) маршрутизируются только домены выбранного сервиса |
| **Telegram** | Отдельный профиль туннеля для доменов Telegram, независимо от остальных карточек |

- Discord, YouTube, Twitch и Telegram настраиваются **отдельно**
- Игры и другие приложения продолжают использовать обычное подключение
- **STOP** сбрасывает активные правила и возвращает стандартную конфигурацию сети

Публичный исходник содержит клиент, UI и установщик. Серверные endpoint’ы и runtime-секреты не публикуются, чтобы не раскрывать инфраструктуру; логика клиента и формат профилей видны в репозитории.

## Что умеет

| | |
|---|---|
| **Discord** | Маршрутизирует трафик Discord через выбранный профиль подключения; чаты, голосовые каналы и демонстрация экрана работают в обычном клиенте |
| **YouTube** | Маршрутизирует трафик YouTube в Chrome / Edge через локальный прокси-профиль. После включения один раз перезапустите браузер |
| **Twitch** | То же для Twitch в браузере; можно держать вместе с YouTube |
| **Telegram** | Отдельный профиль для десктопа и веба Telegram |

Дополнительно:

- Несколько карточек можно держать включёнными сразу  
- Steam / CS2 и другой трафик вне выбранных сервисов не уводятся в общий туннель  
- Обновление из приложения кнопкой **Обновить**  
- **STOP** или выход из трея — активные правила снимаются

## Безопасность и приватность

- Права администратора нужны для загрузки сетевого драйвера и применения правил маршрутизации  
- Для Discord используется **WinDivert** (официальный проект: [reqrypt.org/windivert](https://reqrypt.org/windivert.html); в поставке — `WinDivert.dll` / `WinDivert64.sys` рядом с winws)  
- Перехватывается сетевой трафик, попадающий под активные фильтры карточек; содержимое приложений OnixBoost не читает  
- Серверные конфигурации и секреты инфраструктуры не публикуются  
- Приложение **не собирает** пароли, содержимое переписок, историю браузера и платёжные данные  
- Сетевые обращения клиента ограничены служебными задачами: проверка обновлений (GitHub Releases), синхронизация публичных списков хостов/IP для профилей, проверка доступности сервисов

## Быстрый старт

1. Скачайте **[Setup.exe](https://github.com/OnixV-1/OnixBoost/releases/latest/download/OnixBoost-Setup.exe)** из [Releases](https://github.com/OnixV-1/OnixBoost/releases/latest)  
2. Установите и запускайте **от администратора**. Рекомендуемый путь латиницей (например `C:\OnixBoost`): профили DPI используют относительные пути к драйверу и спискам — каталоги с не-ASCII в пути на части систем дают сбои загрузки  
3. Нажмите карточку → дождитесь статуса **Online**  
4. Для YouTube / Twitch после включения один раз **перезапустите браузер**  
5. Повторный клик выключает карточку, **STOP** — снимает все активные правила

## Обновления

При запуске и в фоне проверяется новая версия. Если есть — в шапке кнопка **Обновить**.

Актуальный установщик всегда в [latest release](https://github.com/OnixV-1/OnixBoost/releases/latest).  
Хеш текущего Setup — в блоке выше и в описании релиза.

## Если не работает

1. Запуск от администратора; при ложных срабатываниях AV — исключения для папки установки  
2. **STOP** → 5–10 секунд → снова карточка  
3. YouTube / Twitch: **Chrome или Edge**, перезапуск браузера после статуса Online  
4. Discord: перезапуск клиента Discord после статуса Online (первая установка может долго качать обновление клиента)  
5. Переустановка с официального Setup в путь латиницей

## Частые вопросы

### Это VPN на весь ПК?
Нет. Изменяется маршрутизация только выбранных сервисов; остальной трафик системы не переводится в общий туннель.

### Затронет ли YouTube / Twitch игры (Steam, CS2)?
Нет. Профили YouTube/Twitch не меняют системный маршрут по умолчанию для игр.

### Антивирус удаляет файлы
См. блок про WinDivert выше, затем переустановите с официального Setup и сверьте SHA-256.

### После выключения странный интернет
**STOP** или выход из трея. Активные правила должны сниматься автоматически; иначе — перезапуск сетевого адаптера или ПК.

### Почему не все конфиги в репозитории?
Клиент и установщик открыты. Серверные endpoint’ы и секреты инфраструктуры закрыты, чтобы ими нельзя было злоупотребить вне официальных сборок. Схема работы карточек описана в разделе [Как это работает](#как-это-работает).
